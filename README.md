# Promic Solution App


# Descrição
O Promic Solution App é um aplicativo desenvolvido em Flutter para a divulgação de programas estudantis, como bolsas de monitoria e programas de iniciação científica. O app permite que alunos visualizem essas oportunidades por meio de um feed similar ao das redes sociais, conectando alunos e professores a esses programas.

# Funcionalidades:
Feed de Programas Estudantis: Visualização de bolsas de monitoria e iniciação científica.

Conexão entre Alunos e Professores: Permite a interação entre alunos e professores por meio de postagens e comentários.

Notificações de Novas Oportunidades: Alunos podem receber notificações sobre novos programas e oportunidades de pesquisa.

# Tecnologias e Arquitetura
Este projeto foi desenvolvido utilizando as seguintes tecnologias e práticas:

Flutter: Framework para desenvolvimento mobile.

MobX: Utilizado para gerenciamento de estado reativo no app, facilitando a atualização automática da interface quando os dados mudam.

Supabase: Utilizado como backend as a service (BaaS), fornecendo autenticação, banco de dados em tempo real, e outros serviços para o aplicativo.

Modular: Sistema de navegação modular e injeção de dependências, permitindo uma arquitetura escalável e organizada.

Clean Architecture: Adotada para organizar o código de maneira limpa, separando as responsabilidades em camadas distintas, facilitando a manutenção e escalabilidade do sistema.

Padrão Repositório: Utilizado para gerenciar o acesso e persistência de dados, criando uma camada de abstração entre o app e o banco de dados.
